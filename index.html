Pre-Handover Assessment

Current Issues Found

🔴
Root disk 89% full
Only ~1.1 GB free on the 10 GB root volume. Risk of Apache crash, PHP session failure, and silent Moodle cron failure if disk fills up.
🔴
Moodle 4.1 — Past end of support
Security support ended May 2025. Running unsupported for 15+ months. No security patches being received.
🟡
PHP 7.4 — End of life since Nov 2022
No security updates. Moodle 4.5 requires PHP 8.1+. Upgrade needed as part of migration.
🟡
Debian 11 — LTS ends August 2026
OS is at end of long-term support. No further security patches from Debian security team.
🟡
Moodle cron fails silently
Output directed to /dev/null. Email delivery, course completions, and reports would stop without any alert.
🟡
IMDSv2 not enforced + EBS unencrypted
Root and data EBS volumes are unencrypted. IMDS allows v1 requests — security best practice not met.
